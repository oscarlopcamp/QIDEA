# QIDEA

**Have a quantum idea? Build it here.**

QIDEA is a quantum and hybrid (classical + quantum) programming IDE that runs entirely in your browser.
Write Qiskit code, simulate circuits, and manage a full hybrid project across classical, quantum and integration lanes. Nothing to install.

## Develop

```bash
npm install
npm run dev
```

## Deploy

Every push to `main` builds the site and deploys it to GitHub Pages (`.github/workflows/deploy.yml`).
In the repository settings, set **Pages → Source** to **GitHub Actions**.
